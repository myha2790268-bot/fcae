# Các câu lệnh tiếp nối cho Codex

## Giai đoạn M0–M1
`Đọc AGENTS.md + 09–15. Xây PySide6 shell với 11 menu, mock 500 Page/50 dự án, Project Manager và Project Bulk Video Publisher 3 bước; SQLite + migrations. Run UI, pytest, ruff, PROGRESS.md và commit. Không chỉ vẽ UI.`

## Giai đoạn M2
`Tiếp tục từ PROGRESS.md. Triển khai publish_batches + publishing_jobs, media validation, durable queue, idempotency, crash recovery, audit logs. Mock provider test offline/duplicate. Chạy tests và cập nhật tiến độ.`

## Giai đoạn M3
`Thêm Meta OAuth và MetaGraphProvider theo tài liệu mới nhất, quyền tối thiểu, kết nối một vài test Page được cấp quyền. Nếu không có token thì chạy mock. Không bịa kết quả Meta; chạy integration tests khi có credentials.`

## Giai đoạn M4
`Triển khai cloud scheduling độc lập gồm API, worker, PostgreSQL, object storage, TLS/auth, signed jobs, media upload và remote acknowledgement. Native Meta schedule chỉ khi hỗ trợ loại nội dung. Test client tắt nhưng cloud mock vẫn chạy.`

## Giai đoạn M5
`Hoàn thành Comment Center, Analytics, Account & browser profiles, proxy hợp lệ, Content Library, backup/restore, installer NSB_Page_Manager_Setup.exe. Load test 500 Page và cập nhật PROGRESS.md.`

## Tiếp tục sau khi mất lịch sử chat
`Đọc AGENTS.md, README.md, PROGRESS.md, IMPLEMENTATION_PLAN.md và git log. Xem mã nguồn, tests, lỗi còn lại; tiếp tục milestone chưa xong, không viết lại những phần đã ổn.`
